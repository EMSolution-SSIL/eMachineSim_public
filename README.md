# eMachineSimDocs

Public documentation site for **eMachineSim**, a Python API based analysis toolset for electric-machine design support.

- Documentation site: https://emsolution-ssil.github.io/eMachineSimDocs/
- Repository: https://github.com/EMSolution-SSIL/eMachineSimDocs

This repository contains the built static HTML/CSS/JavaScript output for the eMachineSim Docusaurus documentation site. The editable documentation source is maintained separately and then built into this repository for GitHub Pages publication.

## What eMachineSim Supports

eMachineSim focuses on support analyses for electric-machine development, including:

- steady thermal conduction analysis;
- thermal equivalent-circuit coupling;
- BDF/QVOL loss import workflows;
- coil copper loss and permanent magnet loss inputs;
- stator/rotor gap thermal coupling diagnostics;
- centrifugal-force structural analysis;
- modal and vibration/NVH support workflows;
- small electrostatic sample workflows.

The documentation also describes how to use **SKILLS + coding AI** to prepare `input.json` files, choose examples, run analyses through the Python API, and inspect diagnostic CSV outputs. This repository also includes an experimental eMachineSim MCP server so AI agents can inspect Examples, input JSON files, and result CSV diagnostics through structured tools.

## Repository Contents

The published site is generated by Docusaurus and includes:

- `index.html`, `docs/`, `en/`, `assets/`, `img/`: built GitHub Pages site files;
- `Examples/`: public sample datasets referenced by the documentation, SKILLS, and MCP server;
- `skills/`: coding-AI reference files for eMachineSim workflows;
- `mcp_servers/emachinesim/`: MCP server for AI-agent access to examples, input JSON inspection, diagnostic CSV summaries, guarded JSON variant writing, and Python API based single-case solves;
- `.nojekyll`: GitHub Pages marker file for static assets;
- `LICENSE*.md`, `NOTICE.md`, `TRADEMARKS.md`: license and notice drafts for public review.

## AI Agent Support

eMachineSim is intended to be used from the Python API / pyd module. The public
support materials are split as follows:

- **Docs** explain what eMachineSim can do and how the workflows are intended to
  be used.
- **Examples** provide public input files and result files that users and AI
  agents can inspect.
- **SKILLS** provide workflow guidance for coding AI.
- **MCP server** provides structured tools for AI agents to inspect examples,
  read `input.json`, summarize thermal CSV diagnostics, and create focused JSON
  variants.

For MCP setup and tool-level details, see
[`mcp_servers/emachinesim/README.md`](./mcp_servers/emachinesim/README.md).
