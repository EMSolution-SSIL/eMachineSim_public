# Electrostatic Workflow

Use this reference for electrostatic examples and future electrostatic expansion.

Important sample locations:

- `Examples/electrostatic/`
- `examples/` if electrostatic examples are mirrored there.

Current scope:

- Electrostatic analysis exists but is currently a smaller feature area than thermal and structural workflows.
- Use existing examples as the source of truth for supported input JSON fields.

Typical workflow:

1. Select the closest electrostatic sample.
2. Define mesh, materials or permittivity settings, and electric boundary conditions.
3. Solve through the Python API.
4. Inspect field/potential outputs generated by the sample.

When documenting electrostatic features:

- Say "electrostatic", not "electromagnetic", unless discussing imported electromagnetic loss data from another tool.
- Mention that electrostatic support may expand in future versions.
